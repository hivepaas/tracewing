The first release of tracewing, an HTTP(S) debugging proxy for everything a browser's own tools cannot see: mobile apps, desktop apps, servers and AI agents.

- **See every request.** HTTP/1.1 and HTTP/2, WebSocket, server-sent events, gRPC and GraphQL, over HTTPS through a certificate authority made for your computer alone.
- **No proxy settings needed.** Pick an app and tracewing takes its connections as they are. Nothing is told to the app, and nothing else on the computer changes. macOS hands the connections over through a network extension; Windows and Linux through an adapter of tracewing's own. Everything you did not pick goes straight through untouched, its TLS never opened. This is for apps that have no proxy setting, or ignore the one they have.
- **HTTP/3 and QUIC are not a blind spot.**
  - tracewing can hide servers' offers of HTTP/3, so an app stays on HTTP/2.
  - It can block UDP 443, so a client falls back.
  - An attempt that was refused still arrives as a flow, with the server it asked for and the program that sent it.
  - For a program you picked on Windows or Linux, tracewing speaks HTTP/3 at both ends. The program's QUIC ends at tracewing, the HTTP/3 inside is recorded like any other flow, and tracewing asks the server over HTTP/3 too. This is off by default, under Settings › HTTP/3.
- **Big sessions stay smooth.** A million requests scroll at your display's pace, and large bodies stream through instead of piling up in memory.
- **Read what is inside.** JSON, XML, Protobuf, MessagePack and CBOR laid out; tokens, cookies and timings explained; two requests compared side by side.
- **Pause and edit.** Breakpoints hold a request or a response, and WebSocket messages too, until you send it on, changed or not.
- **Change traffic on the way.** Rules block, answer from a file, send to another host, rewrite headers and bodies, or slow the network down. For the rest, a few lines of JavaScript.
- **Made for AI work.** LLM API streams put back together, tokens and tool calls, and an MCP server so your AI tools can search and read what tracewing recorded.
- **Web3 too.** JSON-RPC calls and their calldata read by your contracts' ABIs, and a warning when an edit breaks a signed transaction.
- **Phones and emulators.** Set up from a QR code, with Android emulators (14 and later too) and the iOS Simulator trusted in one click. For an app that ignores the phone's proxy setting, the phone can join a WireGuard tunnel instead.
- **Works at work.** Through your company's proxy, NTLM included, with your company's own CA, client certificates and TLS keys for Wireshark.
- **No window needed.** `tracewing capture` records on a server or in CI, and writes HAR.
- **Made for every day.** 15 languages, light and dark, a text size of your choice, and layouts you can name. It runs on your computer and sends nothing anywhere, except a daily look at GitHub for a new version, which Settings › About turns off. On Windows and macOS a new version installs in one click, as tracewing quits.

tracewing is free software (GPL-3.0-or-later). All of this release is free: there is nothing to buy and nothing to sign in to.

**macOS:** 13 Ventura and newer. The app is signed with a Developer ID and notarized, so it opens without a detour.

**Linux:** the packages run on glibc 2.35 and newer (Ubuntu 22.04, Debian 12). They are not signed: `dnf` warns and goes on, and `zypper` needs `--no-gpg-checks`.

**Windows:** the installer is not signed either, so SmartScreen asks the first time (More info › Run anyway). The installer and the `.zip` include Wintun 0.14.1 from wintun.net, which is what takes programs' connections with no proxy settings. Its own license is beside it, in `WINTUN-LICENSE.txt`.

`SHA256SUMS` holds every file's SHA-256.

It also [builds from source](https://github.com/hivepaas/tracewing/blob/main/docs/building.md) on all three — one `make release`.

## After you install it

Open tracewing. Its proxy listens on 127.0.0.1:9090, and **Set up** walks through trusting the certificate authority it just made and sending this computer's traffic to it.

To take an app's connections with no proxy settings, use Settings › Capture › Apps (Programs on Windows). Each system asks for permission once:

- **macOS** asks you to allow tracewing's network extension in System Settings.
- **Windows** starts tracewing again as an administrator.
- **Linux** asks once for permission to make tracewing's adapter.

If tracewing is ever killed while it holds the system proxy, the machine loses the network until the setting goes back. tracewing puts it back by itself within a minute, and `tracewing recover` does it at once.
