A release of fixes: updates that install on Windows, everything saved when you close the window, the system proxy put back in full on a Mac, and a proper Windows app.

**On Windows, install this one by hand.** tracewing 0.1.0 and 0.1.1 on Windows find a new version and download it, but never start its installer. Download `tracewing_0.1.2_windows_x86_64-setup.exe` below and run it once: it installs over the copy you have, and keeps your settings and certificate authority. From 0.1.2 on, updates install by themselves.

- **Updates install on Windows.** A downloaded update now installs as tracewing quits; before, its installer never started.
- **Closing the window saves everything.** Closing tracewing's window skipped everything it does as it quits, on every system: settings just typed and the layout were not saved, and a downloaded update was not installed. Quitting from the menu or with the keyboard was not affected.
- **The system proxy comes back in full on a Mac.** When tracewing was killed or crashed, the two helpers that put the system proxy back could get in each other's way, and leave tracewing's list of hosts that bypass the proxy in place of yours. They now take turns, and a cut-short restore is finished by the next one.
- **A Windows app, not a console one.**
  - `tracewing.exe` has its icon in Explorer, the Start menu and the taskbar, and opens no console window beside its own.
  - In a terminal, `tracewing capture` and the other commands go to `tracewing.com`, installed beside it. It prints, waits, and stops with Ctrl+C as before.
- **An update is shown on the title bar.** A badge beside the appearance switch says *Update available*, then *Restart to update* once it is downloaded. It replaces the row over the traffic. A click opens Settings › About.

## Updating

- **Windows:** by hand this once (above).
- **macOS:** Settings › About › *Download and install*, then *Restart now*. That installs it on 0.1.0 and 0.1.1 too, since it quits with the window open.
- **With the `.deb` or `.rpm`:** About shows the commands to run, with the file's SHA-256.

**macOS:** 13 Ventura and newer. The app is signed with a Developer ID and notarized, so it opens without a detour.

**Linux:** the packages run on glibc 2.35 and newer (Ubuntu 22.04, Debian 12). They are not signed: `dnf` warns and goes on, and `zypper` needs `--no-gpg-checks`.

**Windows:** the installer is not signed, so SmartScreen asks the first time (More info › Run anyway). The installer and the `.zip` include Wintun 0.14.1 from wintun.net, which is what takes programs' connections with no proxy settings. Its own license is beside it, in `WINTUN-LICENSE.txt`.

`SHA256SUMS` holds every file's SHA-256.

tracewing is free software (GPL-3.0-or-later), and all of it is free: there is nothing to buy and nothing to sign in to. It also [builds from source](https://github.com/hivepaas/tracewing/blob/main/docs/building.md) on all three — one `make release`.
